# Carex littledalei histone and drought-response analyses

This repository provides the curated analysis bundle supporting the manuscript:

- [`carex-littledalei-analysis-public-bundle.zip`](carex-littledalei-analysis-public-bundle.zip) contains 13 Python/R analysis scripts, the processed 84-gene by 18-sample Carex PEG FPKM matrix and sample metadata, public accession manifests, selected derived numerical tables, and a detailed README.
- The bundle also contains `SHA256SUMS.tsv` to check every extracted file. SHA-256 of the ZIP: `54f3cc94aa56dc02f98f93dbda7119fd752495de9835db9a947e05581128c8ca`.

Download and extract the ZIP to inspect the directory structure and detailed reproducibility notes. These are processed inputs and results, not raw FASTQ/BAM files. Reference FASTA files and other third-party source data are not redistributed. Some analyses require external inputs and software, so this is not a one-command end-to-end reproduction package.

The original analysis code is released under the [MIT License](LICENSE). The processed data are shared for inspection and reanalysis; this software license does not assert rights over third-party source data. Computational support for candidate prioritization does not constitute experimental validation of gene function or drought tolerance.
